# 🤖 AI Crypto Trading Bot

ระบบวิเคราะห์ตลาดและช่วยตัดสินใจเทรดคริปโตเคอร์เรนซีอัตโนมัติ พัฒนาด้วย Python, CCXT และ Gradio บน Hugging Face Spaces

## 🚀 ฟีเจอร์หลัก
- **Real-time Market Analysis:** ดึงข้อมูลราคาย้อนหลังและสถานะตลาดปัจจุบันผ่าน API ของ Exchange
- **Indicator Calculation:** คำนวณค่าเฉลี่ยเคลื่อนที่ (Moving Average / SMA) เพื่อวิเคราะห์แนวโน้มราคา
- **AI Signal Generation:** ระบบประมวลผลสัญญาณซื้อ/ขายเบื้องต้นอัตโนมัติ
- **ZeroGPU Support:** รองรับการประมวลผลประสิทธิภาพสูงบนโครงสร้างพื้นฐานของ Hugging Face

## ⚙️ การใช้งาน
คลิกปุ่ม **"รันระบบวิเคราะห์ตลาด"** บนหน้าจอแดชบอร์ด เพื่อให้บอทเริ่มดึงข้อมูลและแสดงผลสัญญาณการเทรดล่าสุดทันที
